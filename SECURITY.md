# Security

The plugin has no install scripts, MCP servers, hooks, scheduler, bundled agent, or external helper dependencies. Source is readable. The only live execution is the separately installed official Apify CLI, invoked with argument arrays and fixed endpoint patterns.

Paid starts need a reviewed plan hash and an explicit user decision. The helper reserves a unique ledger, disables platform restarts, supplies time/cost limits, and never automatically replays an unknown request. It does not read tokens, auth files, or unrelated data. Imported post text is untrusted evidence. Arbitrary post links are not fetched by the helper.

CSV cells with a leading spreadsheet formula indicator are escaped. Reports escape imported Markdown text; accepted source links are HTTPS public post URLs on allowed hosts. Local output permissions are restrictive, and existing output files are not overwritten automatically. Live output checks bind each run to the planned Actor and exact build.

Report a security concern using a sanitized description through [GitHub's security reporting surface](https://github.com/khadinakbarlabs/buyer-intent-lead-finder/security) when enabled. If unavailable, open a minimal issue requesting a private reporting channel without publishing exploit details or secrets. There is no guaranteed response-time commitment.
