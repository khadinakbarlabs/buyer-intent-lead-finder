# Support

Maintainer: Khadin Akbar Ventures LLC.

Use the [issue tracker](https://github.com/khadinakbarlabs/buyer-intent-lead-finder/issues) for setup, compatibility, or output defects. Include plugin version, operating system, Node/Apify CLI versions, the command name, a short error description, and a synthetic or redacted reproduction.

Never post API tokens, authentication files, private links, actual prospect records, customer data, or full account/run output. The CLI's `doctor` checks prerequisites without printing credentials; `doctor --live` additionally confirms the authenticated Apify username.

Missing local prerequisites affect live collection; they do not block offline examples or analysis. A failed or unknown start needs inspection in Apify before any new collection. See the [recovery guide](skills/buyer-intent-lead-finder/references/cli-guide.md).

Security concerns should follow [SECURITY.md](SECURITY.md).
